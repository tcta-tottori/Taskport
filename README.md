# Taskport

タスクとスケジュールを、どの端末からでも・どんな方法でも入れられて、必要な形で出せるようにするための個人用ハブ。

**port = 入出力ポート。** 多数の入口と出口が、一つの台帳につながっている。

---

## 入口（Ports In）

| 経路 | 使う場面 |
|---|---|
| 音声 | 現場を歩いている時、会議直後。喋るだけで複数タスクに分解される |
| キーボード（自然文） | PCの前。メールの文面をそのまま貼ってタスク化 |
| フォーム直接 | 件名と期限だけ分かっている時の最短経路 |
| 他アプリから共有 | Gmail・LINE の共有メニューから直接投げ込む |

自然文はすべて同じパイプラインを通り、AIがタスク候補に分解する。
**候補は必ず確認画面に出る。無確認では登録されない。**

## 出口（Ports Out）

- 一覧ビュー（今日 / 今週 / すべて / 完了）
- スケジュールビュー（勤務時間のタイムライン＋2週間の日付軸）
- 分析ビュー（処理の推移・区分別・優先度分布・入口別）
- Googleカレンダーへ書き出し（登録URL / .ics）
- 日報・朝会用テキスト
- CSV

---

## 勤務時間

スケジュールと稼働率の計算に使う。設定画面から変更できる。

| 項目 | 既定値 |
|---|---|
| 始業 | **8:20** |
| 昼休憩 | **12:20 〜 13:05** |
| 終業 | **17:10** |
| 実働 | **8時間05分**（485分） |

「今日のタスクを全部やったら勤務時間に収まるか」を、一覧の上と分析画面のゲージで出す。
見込み時間を入れていないタスクは、設定の既定値（初期値30分）で積む。

## 動作環境

- **Android Chrome**（主）
- **PC Chrome**（副）
- PWA。ホーム画面に追加してオフラインでも動く
- 音声入力は Chrome 前提。非対応環境では自動的にキーボード入力に切り替わる

## データの扱い

- 音声は端末内で文字に変換され、**音声データそのものは外部に送信されない**
- AIに渡るのは変換後のテキストのみ。APIキーは Cloudflare Workers 側に保持
- タスクは端末内（IndexedDB）に保存。設定画面から JSON で書き出し・取り込みができる

## 開発

```bash
npm install
npm run dev        # 開発サーバ
npm run build      # 本番ビルド（dist/）
npm run preview    # ビルド結果の確認
npm run lint       # 型チェックのみ
```

`main` に push すると GitHub Actions が `gh-pages` ブランチへ配信する。
Pages の Source は「Deploy from a branch → gh-pages / (root)」に設定しておく。

### AI構造化プロキシ（任意）

**未設定でもアプリは動く。** そのときは端末内のかんたん解析で候補を作り、
確認画面に「かんたん解析で作りました」と明示する。精度を上げたい場合だけ立てる。

```bash
cd worker
npm install
npx wrangler secret put ANTHROPIC_API_KEY   # キーはここだけに置く
npx wrangler deploy
```

出た URL をアプリの「設定 → AI構造化プロキシ」に入れる
（または `.env` の `VITE_PARSE_ENDPOINT` に入れてビルドする）。
詳しくは [`worker/README.md`](./worker/README.md)。

### 画面

| 画面 | 役割 |
|---|---|
| 一覧 | 今日の稼働ゲージ＋タブ（今日 / 今週 / すべて / 完了） |
| スケジュール | 勤務時間の帯に予定を置いた1日タイムライン＋2週間の日付軸 |
| 分析 | 稼働率・処理の推移・区分別・優先度分布・入口別 |
| 設定 | 勤務時間、プロキシURL、JSONバックアップ |

書き出しはヘッダー右上のボタンから。

詳しい設計は [`design.md`](./design.md)、
実装時の規約は [`CLAUDE.md`](./CLAUDE.md) を参照。
